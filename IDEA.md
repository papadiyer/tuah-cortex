Dalam ekosistem agentic, ini adalah seni bina Multi-Layered Memory Architecture:

Memory Curator: Bertindak sebagai agentic filter (pengasing fakta vs episod/pengalaman).

Experience (Graphify): Mengendalikan structural & relational dependencies (bagaimana kod, fail, atau entiti saling berhubung).

Knowledge (Vector DB): Mengendalikan unstructured semantic search (mencari dokumentasi, nota, dan perbualan lepas berdasarkan maksud).

Context Builder: Menyatukan (merge) carian graph + vector menjadi prompt padat untuk dipasok ke Jebat.

Strategy Implementasi (Hermes ➔ Lekiu)
Jebat/Hermes akan bertindak sebagai Architect & Memory Curator.

Lekiu (Claude Code) akan bertindak sebagai Builder yang menulis codebase (Python/TypeScript script, SQLite/Vector DB setup, dan hooks).
